# Capstone 5G FWA Rural

Proyecto de Gestión de Telecomunicaciones II enfocado en la planificación y evaluación técnico-económica de una red 5G FWA para conectividad rural.

## Estructura

- `data/`: dataset y parámetros del escenario.
- `notebooks/`: notebook base y notebook de trabajo.
- `docs/`: documentación, supuestos y validaciones.
- `results/`: gráficas y resultados generados.
